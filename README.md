Overview
The Simple Interest Calculator is an elegant financial tool designed to compute simple interest earnings with precision and clarity. Built with modern web technologies, it offers financial professionals, students, and individuals a reliable way to perform quick interest calculations.

✨ Features
🎯 Accurate Calculations - Precise simple interest computations using standard financial formulas

💫 Modern UI/UX - Clean, professional interface with smooth animations

📱 Responsive Design - Optimized for desktop, tablet, and mobile devices

⚡ Instant Results - Real-time calculation updates

🎨 Professional Styling - Corporate-friendly design with IBM-inspired aesthetics

📊 Clear Visualization - Easy-to-read results with detailed breakdown

🧮 Financial Formula
The application utilizes the standard simple interest formula:

text
I = P × R × T
A = P + I
Where:

I = Simple Interest

P = Principal Amount ($)

R = Annual Interest Rate (%)

T = Time Period (years)

A = Total Accumulated Amount

🏁 Getting Started
Prerequisites
Modern web browser (Chrome 90+, Firefox 88+, Safari 14+)

No additional dependencies required

Installation
Clone the repository

bash
git clone https://github.com/Jdmora91/SimpleInterestCalculator-IBM-Curse.git
Navigate to project directory

bash
cd SimpleInterestCalculator-IBM-Curse
Open the application

bash
# Open in default browser
open index.html

# Or serve with local server (recommended)
python -m http.server 8000
# Visit http://localhost:8000
💻 Usage
Enter Principal Amount - Input the initial investment sum

Set Interest Rate - Specify the annual interest rate percentage

Define Time Period - Enter the duration in years

View Results - Instant calculation of interest earned and total amount

Example Calculation
text
Principal: $10,000
Rate: 5% per year
Time: 3 years

Interest = $10,000 × 0.05 × 3 = $1,500
Total = $10,000 + $1,500 = $11,500
